# ConsoleDataBase

Учебная консольная программа на Java для работы с одной таблицей: создание столбцов, добавление, редактирование, удаление и просмотр строк. Данные сохраняются автоматически через Java-сериализацию в `save.ser` в текущем рабочем каталоге. Внешняя СУБД не требуется.

## Требования и запуск

В `pom.xml` указан Java 18 для исходников и целевого байткода. Для сборки нужны JDK 18 или новее и Maven; Maven Wrapper в репозитории отсутствует.

Из корня проекта:

```powershell
mvn package
java -jar target/DataBaseMaven-1.0-SNAPSHOT.jar
```

Главный класс `com.vladimir.java.Main` уже прописан в manifest JAR через `maven-jar-plugin`. При отсутствии читаемого сохранения программа предлагает создать новую таблицу.

## Команды меню

- `ADD` — добавить строку.
- `EDIT` — изменить строку по ID.
- `DELETE` — удалить строку по ID.
- `SHOW` — вывести таблицу.
- `CREATE` — создать таблицу заново.

Исходники находятся в `src/main/java/com/vladimir/java/`: `console/` отвечает за меню и вывод, `database/` — за таблицу, `models/` — за её элементы. В репозитории сохранены существующие `save.ser` и содержимое `target/`; запуск программы может обновить сохранение.
